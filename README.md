## 课程列表

- 文件：[环论动画课程.html](环论动画课程.html)

- 形式：单文件 HTML，MathJax 已内联，完全离线可用
- 交互：逐步推进、自动放映、字幕、术语速查、随堂练习

直接双击 `环论动画课程.html` 即可在浏览器中打开。
